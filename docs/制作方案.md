# 制作方案(基于 2026-09-24 调研)

> **历史文档**:这是项目启动时的初版方案,其中"grok 视频片段"路线已被否定(接口内容错乱,T014a),实际管线历经 v1–v8 迭代。
> 当前管线(v8:Gemini 模块化板件 + 代码骨骼引擎)见根 `README.md`;路线论证见 `research/2026-09-27-精美动画升级方案.md`;版本历史见 `plantree/plans/001-birthday-video/roadmap.md`。

## 总体管线

```
剧本/分镜 → AI 生关键帧图像 → AI 图生视频片段(6–10s/段)
        → TTS 旁白/台词 + BGM/音效 → ffmpeg 合成 1080p 成片
```

- 生图/生视频全部走**云端 API**,本机只做合成与编码(决策见 `docs/plantree/plans/001-birthday-video/decisions/001-cloud-api-pipeline.md`)。
- 成片规格:1920×1080(16:9)、30fps、H.264(nvenc 加速)、约 4 分钟。

## 资源分工

| 环节 | 首选 | 备选 | 说明 |
|---|---|---|---|
| 角色设定图/关键帧 | gpt-image-2(chatgpt2api) | grok-imagine-image(grok2api,在线可用) | gpt-image-2 画质与文字渲染更好,但端点当前 502,需修复 |
| 图像编辑(角色一致性) | gpt-image-2 `/v1/images/edits` | grok-imagine-image-edit(需 Super) | 基于角色设定图生成各镜头帧 |

| BGM/音效 | 免版税下载(Pixabay Music 等) | — | 本机无素材库,需准备 |
| 合成/字幕 | ffmpeg + ass 字幕 | — | Noto Sans CJK SC 已具备,nvenc 硬编 |

## 角色一致性策略(关键难点)

1. 先产出**角色设定图**:开开(蓝色 Q 版挖掘机、大眼睛)三视图 + 工程车小队成员(翻斗车/吊车/搅拌车/推土机)各一张,统一"布鲁伊式"画风提示词模板。
2. 每个镜头以设定图为参考,用**图像编辑/参考图接口**生成关键帧,而不是纯文本生图。
3. 视频片段统一走**图生视频**(grok-imagine-video 的 `image` 参数),保证每段开头与关键帧一致。
4. 建立 `assets/images/characters/` 设定集,所有 prompt 复用同一份风格描述词。

## 镜头与工作量估算(240s)

- 已定稿:片头 28s + 互动 30s ≈ 6–8 个镜头
- 后半段约 182s ≈ 12–16 个镜头
- 全片约 20–24 个镜头;若每个镜头 1 段 AI 视频(8s)+ 部分静帧 Ken Burns(平移缩放)补足,预计需 **15–20 段 AI 视频**、**25–35 张关键帧图**。
- 建议先做 1 个镜头端到端试产(生图→生视频→TTS→合成),验证质量与成本后再批量。

## 音频方案

- 旁白(温柔童趣女声)与开开台词(童声)分轨生成,ffmpeg 混音;BGM 全程铺垫(音量 -18dB 左右垫底),音效点缀。
- 字幕:ASS 格式,跟随旁白时间轴,含互动提示字幕(大字号、描边)。

## 前置依赖(阻塞项)

1. grok2api 的 g2a 客户端密钥(管理端 `http://1p.927788.xyz:8000` 创建)+ 确认池内有 Super 级账号(视频/高清图必需)
2. gpt-image-2 端点修复(`tp.927788.xyz` 当前 502)或改用 grok-imagine-image 为主力
3. `uv tool install edge-tts` 并试听选定两种音色
4. 下载 2–3 首童趣 BGM 与基础音效(挖掘声、欢呼声、生日歌伴奏)
5. 剧本后半段定稿
