# V10 正片深度评审 & V11 详细迭代方案

评审对象:`output/v10_feature.mp4`(237s,1920×1080@30)。评审日期 2026-10-04(第二版,深化)。
证据来源:① 全片 40 帧联系表 + 关键帧精看(0/3/75/150/205s)② ffmpeg 场景检测(切镜数 = **0**)③ 源码 `web/src/v10/{feature_timeline,feature,actions,fk,main}.js` ④ `output/feature_vo_durations.json` ⑤ `assets/images/v10/` 资产清单 ⑥ `.trellis/spec/frontend/v10-animation-quality.md` 现行规范。

## 0. 结论(30 秒版)

**v10 解决的是"不穿帮",没解决"好看、好玩、有戏"。** 过去十几轮迭代都在打磨"铲斗别穿履带、关节别断"这类**正确性**问题,规范(L1–L4)也只管正确性;而一部优秀 2D 动画片的价值在**导演、表演、节奏、场景、观众心理**,这些维度在现有体系里**完全没有度量、没有岗位、没有代码模块**。所以不管再迭代多少轮,画面都会"稳而无趣"。

v11 的核心不是修 bug,而是**补齐"导演层/表演层/场景层"三个缺失的层**,并把"动画语言"写进验收规范。

## 1. 根因分析(为什么迭代到 v10 仍不满意)

| 根因 | 说明 | 后果 |
|---|---|---|
| R1 **架构是"舞台剧一镜到底"** | `frame(t)` 在一张 1920×1080 画布上按固定层序绘制,无 camera 变换;所有道具/角色用绝对屏幕坐标(x=480/1240/900…) | 不可能有推拉摇移、视差、特写;要加镜头得重构坐标系 |
| R2 **角色规模失衡** | 挖挖整机约占画面 55% 宽×70% 高,是个"墙";配角只有 460–545px,蛋糕/礼物更小 | 主角吃掉构图,配角与小道具在画面里像"挂件",高潮道具(蛋糕/礼物)不够突出 |
| R3 **挖挖的脸是烘焙在 body.png 里的静态图** | 表情系统只有"眨眼盖片"(每 4s 一次);眼球位置固定向前,眉毛固定,嘴固定微笑。`wawa_expr_laugh/wink.png` 存在但**未接入** | 无法做视线引导、惊讶、期待、开心大笑,表演维度为 0 |
| R4 **动作库只有 6 个循环**(idle/wave/dig/lift/lower/cheer)+ walk(=idle+颠簸) | 时间轴靠"整段 idle"填时长(18–34s、42–58s、67–82s、94–121s、185–204s、222–237s) | 约 60% 以上时长挖挖只在呼吸;动作缺少预备/跟随/过冲 |
| R5 **配角是单张 PNG + 平移/压扁** | `drawPup(img,cfg,t)` 只有 hop/lunge/bounce;无肢体、无表情切换、无朝向翻转;宾果全程抱骨头同一姿势 | "贴纸感",与有骨骼的挖挖风格割裂,也无法演"扑骨头""捂嘴笑" |
| R6 **场景是单层平涂** | `drawDecor` = 纯色背景 + 草带 + 旗串 + 2 束气球 + 灌木剪影;无远/中/近层 | 无空间感、无"寻宝路线"感、走路没有视差 |
| R7 **时间轴按"秒数配额"而非"情绪曲线"编排** | 分镜表按 30/100/40/67s 切配额,每线索 = X 弹入→挖→道具弹出的同一模板 | 三遍同构,无递进、无意外、无悬念、高潮无蓄压 |
| R8 **验收体系只测正确性** | L1 侵入 0 / L2 硬顿挫 0 / L3 目检 / L4 静帧;无镜头数、无静止窗口、无构图、无观众视角 | 模型/脚本全绿,用户仍不满意——**度量与目标错位** |
| R9 **没有观众画像驱动** | 观众是 2 岁宝宝+家长。2 岁宝宝需要:大特写、慢而清晰的动作、重复的"可参与"节拍、强色彩对比、高频的小惊喜;家长需要:有"我家娃的名字/礼物"的情感点 | 237s 的内容密度、字幕大小、互动提示都没按此设计 |

## 3. 设计原则(v11 北极星)

1. **2 岁宝宝优先**:大主体、慢而清晰、重复节拍、强色、每 3–5s 一个"小惊喜"、每 20s 一个"可互动点"(拍手/挥手/叫名字)。
2. **一个镜头一个意图**:交代 / 动作 / 反应 / 展示 / 高潮,不混用。
3. **角色靠表演立住,不靠道具弹出**:惊喜先发生在脸上,再发生在道具上。
4. **空间可信**:前后层、视差、阴影、遮挡。
5. **正确性已达标,不再退步**:L1/L2 全保留,新动作必过。
6. **竖切片先行**:一个线索做到"成片级"后再复制,杜绝整片返工。

## 4. 技术/美术方案(分模块)

### 4.1 导演层:虚拟摄像机 + 镜头单元
- **世界坐标**:定义世界宽 4800×高 1080,画面窗口 1920×1080;`camera = {x, y, zoom, rot=0, shake}`。渲染时 `ctx.setTransform` 统一施加;每层带 `parallax` 系数(远景 0.2 / 中景 0.6 / 主 1.0 / 前景 1.4)。
- **镜头单元数据结构**(`web/src/v11/shots.js`):
  ```js
  { id:'s2a-03', t0:46.0, dur:3.2, cam:{from:{x,y,zoom}, to:{x,y,zoom}, ease:'inOutCubic'},
    purpose:'reaction', actors:{wawa:{action:'surprise'}, bluey:{pose:'gasp', look:'prop1'}},
    transition:'cut' }
  ```
  所有 `renderAt(t)` 仍为纯函数:`shotAt(t)` → 查表 → camera 插值 → 绘制。
- **运镜词汇表**(限定,避免乱):`hold`(定)、`pushIn`(推)、`pullOut`(拉)、`pan`(摇/跟)、`track`(跟随挖挖)、`whipCut`(甩切)、`rack`(焦点/虚化前景)、`shakeSmall`(挖土小震)。
- **景别阶梯**:EWS 远景(交代地点)/ WS 全景 / MS 中景 / CU 特写(脸、道具、蜡烛)。2 岁观众比例:特写 ≥ 25%。
- **平均镜长 5–8s**(宝宝友好;当前 237s)。

### 4.2 表情系统(挖挖)
- 现状:脸烘焙在 body。方案分两档:
  - **A 档(低成本,推荐先做)**:在 body 上方加**程序化脸层**:盖住烘焙眼睛区域(底色=脸米色),用 canvas 重画眼白/瞳孔/眼睑/眉毛/嘴(尺寸取 `FACE.eye_l/eye_r` 实测值)。可参数化:`lookX/lookY`、`lidTop/lidBottom`、`browLift/browTilt`、`mouthOpen/curve`、`cheek`。
  - **B 档(高质)**:用生图 API 生成 6 个表情的 body 脸部贴片,逐帧交叉淡化;风险:贴片与 body 描边接缝。
- **表情集**(≥8):中性、开心(眯眼笑)、惊讶(眼大+眉高+圆嘴)、期待(眼放光+上看)、专注(眉压低,挖土时)、得意/炫耀、害羞/捂嘴笑、大笑。
- **视线系统**:`lookAt(world point)` → 瞳孔偏移 ≤ 眼眶 35%,加 saccade(0.1s 内跳)与 0.3–0.6s 驻留。
- 复用 `wawa_expr_laugh/wink.png` 做 B 档参考。

### 4.3 动作库扩展(`actions.js` → `v11/actions.js`)
新增动作(均为 t 的纯函数,必过 L1+L2):
| 动作 | 用途 | 说明 |
|---|---|---|
| `anticipate_dig` | 挖前预备 | 车身下沉 squash 0.06 + 大臂后摆 6°,0.35s |
| `settle` | 动作后过冲回弹 | 斗/臂 1–2 次衰减振荡 |
| `look_around` | 找线索 | 车身微转+大臂轻摆,配合视线 |
| `nod` | 回应 | 车身点头 bob,0.5s×2 |
| `hop_joy` | 惊喜小跳 | 车身离地≤12px(悬挂 bob),落地压实,履带不离地 |
| `reach_up` | 够气球/帽子 | 大臂上扬到 70°,斗张开 |
| `wiggle` | 蓄力/期待 | 左右小颠步 |
| `bow` | 谢幕 | 斗点头,配合字幕 |
| `scoop_carry` | 托蛋糕 | 已有 pose,补 L1 扫描 |
- **反 idle 规则**:任何 idle 段 ≤3s;连续 idle 超限时自动插入 `micro` 库(look_around/nod/wiggle 轮换,确定性哈希选择保持纯函数)。

### 4.4 配角升级(布鲁伊/宾果)
- 方案 A(推荐):**分件骨骼** — 头(带眼嘴表情)、躯干、双臂(各 2 节)、双腿、尾巴;分件由生图 API 以统一 prompt 生成 + 去底净化(沿用杀白边+去薄雾标准)。
- 方案 B(保底):**姿势序列** — 每角色 6 个整体姿势(站/指/跳起/落地/拍手/笑)+ 姿势间 0.1s 交叉淡化 + 压扁拉伸;表情用头部贴片切换。
- 必备动作:走(4 帧循环)、跳(预备/空中/落地)、指、拍手、捂嘴笑、扑(宾果)、鞠躬、跳舞。
- 朝向:支持水平镜像;**左右视线与行进方向一致**。
- 阴影:每角色椭圆接地影,随跳跃缩放(强化重力感)。

### 4.5 场景
- **三层 + 前景**:远景(山、云,慢)/ 中远(树、围栏)/ 主层(地面、道具)/ 前景(草、花,虚化、快)。
- **地点**:① 后院早晨(幕 1,旗串+房子一角)② 花园(线索 1,花丛)③ 沙坑/滑梯(线索 2)④ 大树下(线索 3)⑤ 空地/金 X(高潮)⑥ 派对桌(结尾,桌布+气球拱门)。同一调色板,换不同远景剪影。
- **环境活物**:云(≤6px/s)、蝴蝶、飘落花瓣、旗串摆动(sin 相位差)、气球漂浮(弹簧)、草随风、烟尘粒子。
- **光**:顶部柔光渐变+暗角;高潮用径向辉光;结尾"金色时刻"色调。
- **伪迹清理**:S4 棕色小方块。

### 4.6 道具与特效
- 惊喜弹出:预备(土鼓包)→ 破土(土粒迸溅+震动)→ 弹出(重力抛物线)→ 落地(squash)→ 辉光/星星。
- 蛋糕:放大 1.6×,**中景特写**;蜡烛数 2 根(数字"2"+火焰);火焰程序化(径向渐变+摇曳);吹灭时火焰向右倒→熄灭→烟。
- 礼物:开盖(分件盖子)→ 纸屑/星星 → 露出内物(与剧本衔接,如小玩具挖掘机)。
- 纸屑:分三类形状+旋转+空气阻力;镜头外也有。

走路镜(视差)→ X1 弹入特写 → 挖挖"专注"表情预备 → 挖(侧面中景+尘土+震动)→ 气球破土(特写)→ 挖挖惊喜反应 → 气球飘走(镜头跟随上摇)→ 布鲁伊鼓掌。

### 线索 2:沙坑 · 派对帽(62–95s,强度 5)· 7 镜

### 线索 3:树下 · 骨头(95–130s,强度 6)· 7 镜

### 幕 4 庆生(172–237s,强度 8)· 10 镜
挖挖去取蛋糕(镜头跟,视差远景换成派对桌)→ 托蛋糕走回(MS 跟拍,小心翼翼表情)→ 放蛋糕(特写落地震动)→ 点蜡烛(CU 火焰)→ 合唱(全景+每句换一个角色特写,节拍 sway)→ 吹蜡烛(大特写,火焰倒向熄灭+烟)→ 欢呼纸屑雨(拉远/升降镜)→ 挖挖看向镜头:"开开,两岁生日快乐!"(CU)→ 标题大字+全员定格(拉远收尾)5s。

## 6. 声音与互动设计
1. **互动节拍**(每 20–25s 一次):旁白提示"开开,挥挥手/拍拍手"→ 画面留 2s 角色等待并做同样动作 → 夸奖。共 6–8 次。

4. 音乐:保持 Carefree 基底;高潮前留白 2s;生日歌分句对齐镜头切换。
5. 沿用现有混音规范与客观终检;**音频终审 = 客观测量+用户亲耳**(不变)。
