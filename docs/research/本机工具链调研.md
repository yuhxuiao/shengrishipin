# 本机工具链调研(2026-09-24)

机器:CachyOS Linux,用户 yuhuxiao。

## 已具备 ✅

| 工具 | 版本/位置 | 用途 |
|---|---|---|
| ffmpeg / ffprobe | n9.0.1 `/usr/bin` | 合成、混音、烧字幕;含 `subtitles`/`ass`/`drawtext` 滤镜 |
| 硬件编码 | h264_nvenc / hevc_nvenc / av1_nvenc + VAAPI | 成片编码加速 |
| 中文字体 | Noto Sans/Serif CJK SC(`/usr/share/fonts/noto-cjk/`) | 字幕烧录 |
| python3 | 3.14.7 | 无 pip 模块,装包走 uv |
| uv | 0.12.15 `~/.local/bin/uv` | Python 工具/venv 入口 |
| node | v22.23.1 | 备用 |
| ImageMagick | convert/magick | 图片批处理 |

## 缺失 ❌ 与补充建议

| 缺口 | 建议 |
|---|---|
| 中文 TTS(全缺) | `uv tool install edge-tts`(在线,中文童声/女声音色好,零 GPU);离线备选 piper(CPU) |
| Python 图像/视频库 | 项目内 `uv venv && uv pip install pillow`(moviepy 非必需,纯 ffmpeg 足够) |
| BGM/音效素材 | 本机 0 个音频文件;从 Pixabay Music 等免版税站下载 2–3 首童趣 BGM + 音效 |

## GPU

NVIDIA GTX 1650 Mobile(4GB VRAM),驱动正常。**结论:本地跑 AI 生图/生视频大模型不现实**,只用于 ffmpeg 编码加速;生成走云端 API。

## 对本项目的影响

合成侧(ffmpeg + 字体 + 硬编)开箱即用;唯一要补的是 **TTS(edge-tts)** 和 **BGM/音效素材**。
