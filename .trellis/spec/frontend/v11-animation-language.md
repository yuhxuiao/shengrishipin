# V11 动画语言规范 (L5) — 导演/表演/场景/叙事

> 起因: v10 通过全部 L1–L4 正确性关卡, 用户仍不满意。根因: 体系只测"不穿帮", 不测"像不像动画片"。本规范补 L5。L1–L4 见 `v10-animation-quality.md`, 继续有效。

## 1. 架构契约
1. **摄像机只做渲染变换**: 不改 FK/动作/probe 的装配空间坐标; L1/L2 probe 在装配空间运行, 结果不受相机影响。
2. `renderAt(t)` 纯函数: 相机、表情、视线、次级动作(弹簧)全部为 t 的解析函数, 禁止跨帧状态; 弹簧用闭式解或固定步长从 t0 重放。
3. 镜头单元 (`V11Shots`) 是渲染/验收/返工的最小单位; 全局时间权威 = shots.js + vo_durations.json。
4. 新增文件只放 `web/src/v11/`; v10 文件只读。

## 2. 导演规则
- 全片 ≥30 镜头, 平均镜长 5–8s, 特写(CU) ≥25%; 每幕以 EWS/WS 交代, 惊喜点必配 CU。
- 屏幕方向: 向右=前进; 摇移与行进同向; 切镜不越轴。
- 构图: 主体落三分线; 配角不得遮挡挖挖脸与铲斗铰链; 前景虚化层不得遮主体。
- 高潮蓄压: 惊喜前 ≥1.5s 静/留白(音乐降), 之后爆发; 慢动作 0.5× 仅用于破土一次。
- 第四面墙: 挖挖可看镜头说话, 每次≥1.2s 对视, 台词与口型同步, 全片 3–4 次。

## 3. 表演规则 (12 原则落地)
- 任何 3s 窗口内必须有可见变化(姿态/表情/视线/位置至少一项); idle 单段 ≤3s, 超限用 `micro` 轮换。
- 惊喜点五拍: 预备→发现→停顿(0.3–0.6s)→反应→庆祝; 反应先脸后道具。
- 每个动作带预备(anticipation)与过冲回弹(settle); 车身受力有 squash(≤0.12) ; 履带不离地, 腾空仅靠悬挂 bob ≤12px。
- 视线: 角色轮流 lookAt 目标(道具/朋友/镜头); 视线跳变 0.1s saccade, 驻留 0.3–0.8s。
- 次级动作: 尾巴/帽球/气球/旗串用弹簧阻尼, 阻尼比 0.3–0.6。
- 配角分件骨骼: 铰点遮挡正确(肩/髋被躯干或衣物盖住), 关节转角限幅, 每角色 ≥6 姿势; 接地椭圆影随高度缩放。

## 4. 场景规则
- ≥4 层视差 (sky 0.05/far 0.2/mid 0.5/main 1/fg 1.5); 地点 6 个, 每线索换景; 同一调色板。
- 环境活物不间断(云/蝶/花瓣/旗/草); 光: 暗角+辉光+金色时刻渐变。
- 伪迹零容忍(无固定杂点/脏斑)。

## 5. L5 自动度量 (scripts/v11_metrics.py)
| 指标 | 阈值 |
|---|---|
| 镜头数 | ≥30 |
| 平均镜长 | 5–8s |
| 特写占比 | ≥25% |
| 最长静止窗(逐帧平均绝对差< ε) | ≤3s |
| 表情状态数(face 日志) | ≥8 |
| 配角姿势数/角色 | ≥6 |
| 配角-铲斗/脸重叠帧 | 0 |
| 层数 | ≥4 |
| 互动节拍 | ≥6 |
| 总时长 | ≤240s |
L1/L2 对所有新动作保持强制; L3 目检增"静音看片测试"(关声音能否看懂故事)。

## 6. 流程
竖切片(线索1 ≈30s)先过 L5+用户; 再复制全片。分幕渲染分目录; agy 评审仍仅用于静帧结构/风格, 不作动态/音频依据。

## 7. 反模式 (v10 教训)
- 只修正确性不补导演层 → 稳而无趣。
- idle 填时长 → 站桩。
- 单图贴纸配角 → 风格割裂。
- 一镜到底 → 无节奏。
