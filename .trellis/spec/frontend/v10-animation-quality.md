# V10 2D 骨骼动画:动作设计与审阅分层规范(v10 样片评审循环十轮后的定论)

> 起因:用户目检 24s 样片发现"挖掘一顿一顿 / 入场一弹一弹",而此前 agy 评审 10 轮(视频×5+sheet×5)均未发现。根因 = 审阅体系只有**静帧关卡**(agy 审图、probe 审位置),没有**动态质量关卡**。本规范把动作设计硬约束与审阅分层定死,每版动作/每版渲染必须按层过检。

---

## 1. 动作设计物理规范(actions.js 关键帧编排)

### 1.1 相位时长与节奏
- **单相位 ≥0.25s**:下压/刮卷/拔起/举升/翻回/回位各自独立成相,禁止在 <0.25s 内完成一个完整动作相位(30fps 下 <8 帧 = 必然顿挫)。
- **循环周期**:挖掘类复合动作 ≥2.2s(真实小挖机单铲 2-3s);待机呼吸 4s;庆祝跳 ≤2s。
- **保持帧(停顿)≤0.15s** 且必须有动画意图(咬土蓄力/落地压实),停顿后必须接爆发帧;禁止"匀速分配+无目的停顿"。
- **禁止 V 形急转**:通道值(boom/stick/bucket)在相邻关键帧间折返(增→减或减→增)时,折返点前后必须有过渡弧(速度归零再反向 = 暴起暴停);优先把折返动作拆成两条单调弧或整体删掉(案例:dig v1 的"翻斗卸土"bucket -19.5→-45→-36 折返段急动 25539°/s²,整段砍掉后动作立顺)。

### 1.2 弹跳与入场
- 垂直轨迹必须**重力抛物线** `dy = -4·H·u·(1-u)`(上升减速/下降加速),禁用 `sin(π·u)`(两端速度剖面对称失真)。
- **空中刚体**:起跳蓄力压(squash)与落地压(squash)只在触地瞬间 ±0.15s 窗口内,空中禁止持续 stretch/squash。
- 入场动作宁单勿多:一次到位跳跃 > 两段兔子跳(多跳必碎)。

### 1.3 段间连续(时间轴)
- 每段终点姿态 ≡ 下段起点姿态(零跳变);动作段时长对齐动作循环整数倍(keyframed 按 t%period 循环,半循环切断 = 跳变)。
- 过渡段(lift/lower)不得直线插值姿态:必须复用主动作(dig)**已验证避让的关键帧链**,禁跳帧(F-C 样条跳帧走捷径 = 履带侵入,案例:lower 首版 971 点侵入)。

### 1.4 位移与附着
- 装配平移(dx)必须配履带滚动(trackScroll=已走距离,节纹+轮转钉);角色/道具附着(renderFrame opts/mBucket 锚点)在 renderAt 纯函数约束下只能**解析重算**,禁止跨帧状态捕获。

## 2. 强制校验关卡(每版动作必过,顺序不可换)

### 2.1 L1 位置 probe(web/src/v10/probe.mjs,60Hz 全帧)
- 铲斗全轮廓 140 点 vs 履带轮圆 (700,969) r215:侵入 0。
- 遮脸 0;铰位 xmax<640;齿尖穿透:扎土/刮土段 ≤15px(齿贴地刮行=真机刮痕,且被土堆 z 序遮挡,视觉正确;其余段必须 >0)。
- **刮土方向必须向车身**(teeth x 递增=拉向自己):v3 教训——dig v1/v2 的"拖刮"是向外推(逆真机),用户一眼判定"挖土和实际不符";B 近点逆解必须带轮圆避让约束(斗背距轮心 >222),teeth 最远伸到 340(土堆近缘)。
- **pose 冻结帧姿态也要扫**(probe.mjs pose b s k)——教训:pose2 (58,-35,44) 绕开动作层扫描,轮圆投影 971 点侵入,评审两轮才发现。

### 2.2 L2 运动学 probe(web/src/v10/probe_kin.mjs,30Hz 重采样=人眼感知对齐)
- 硬顿挫(|急动|>4500°/s²,单帧 5° 阶跃)= **0,不过禁交付**。
- 急动点(>2500°/s²)应趋于 0;每处须能说出动画意图。
- 停顿段(v<1.5°/s 持续>0.15s,非端点)= 0(squash 速度 ×20 折算计入,落地压实不算死停)。
- bob 通道阈值单独 800px/s²(±8px 正弦起伏属正常);循环回绕边界帧跳过(单播动作无回绕,是测量伪影)。
- 阈值标定依据:30fps 渲染,单帧 2.8° 阶跃=2500°/s²(报告线),单帧 5°=4500°/s²(硬失败线);240Hz 采样会把 F-C 正常曲率误报为顿挫,必须 30Hz 重采样。

### 2.3 L3 动态目检(主会话强制,不得跳过)
- 每版渲染抽 ≥2 段连续帧条(每 0.15-0.2s 一帧,≥9 帧)逐段看:速度是否匀顺、相位是否清晰、有无暴起暴停。
- agy/任何模型的"动态质量"结论**一律不作为验收依据**(见 §3)。

### 2.4 L4 静帧评审(agy sheet/单帧)
- 用途**仅限**:结构穿帮(铰接/遮挡/贴地)、风格统一(描边/配色/构图)、素材瑕疵(白边/脏斑)。
- 2560px 拼版格子 ≥640px;关键连接细节(铰链/油缸)送**单帧全尺寸**,不送拼版(拼版压缩后同色系连接必误判)。
- 评审异议必须先经单帧放大对照再决定是否修改;已证伪的误判模式登记在案(§4),同类异议直接引用登记驳回。

## 3. agy 视频评审:能力边界(实测定论)

- gemini 多模态读视频的实际机制是**抽帧**(自曝 ~1 帧/秒):能答"某帧有没有 X",**物理上答不了"动作顺不顺"**(速度曲线需要连续帧)。
- 因此:agy 视频报告可用于静帧级检查;**动态质量(顿挫/跳变/节奏)验收权只属于 L2 probe_kin + L3 人眼目检**。
- 报告时间戳与帧内容存在错位(把 t=15 的内容安到 t=10),所有时间戳只当"区间提示",必须自查复核。

## 5. 目标三标准(阶段 3 门禁)

- 静帧美(L4 过) + 动中稳(L1+L2+L3 过) + 可复用(renderFrame(t,action,mirror,opts) 纯函数 + 时间轴驱动) 同时成立。

## 6. 音频规范(2026-10-03 根因定位后补)

### 6.1 血泪根因:中间格式必须真源

- v2 全曲"叠加刺耳"的真凶不是电平不是选曲,是**混音脚本把 float32 样本配 PCM(s32) 头写临时 wav**,ffmpeg 按整数解读 = 全曲方波失真(实测 440Hz 正弦出 1.3/2.2/3kHz 奇次谐波,正负半周不对称削波)。
- **凡 Python 写 wav 中间文件,一律 `write_s16`(标准 s16 PCM 头);float 数据只走 ffmpeg stdin 管道(`-f f32le`),永不手写 float WAV 头。** 交付前用"纯音测试"验证管线保真:440Hz 正弦过一遍管线,频谱必须只有 440 单峰。

### 6.2 混音结构(scripts/v10_audio.py v3,幼儿向)

- 电平层级(绝对 LUFS):**VO -16 > 生日歌 -25 > SFX -24+微调(点状) > BGM -30 垫底**;SFX 统一低通(履 3.2k/挖 4.2k/其余 7.5-9k)柔化刺耳。
- **VO 闪避(ducking)**:旁白窗内音乐 ×0.50 / 音效 ×0.70,余弦进 0.12s 出 0.5s;闪避深度有下限,再深旁白间隙会死寂。
- **相邻音效事件间隔 ≥0.35s**,禁三事件叠 0.3s 内(案例:15.6 boing+15.65 confetti+15.9 n4 三叠)。
- **双曲交接=crossfade 不叠加**:Carefree 19.7-20.8 淡出至 0,八音盒 20.4 淡入;生日歌用内置八音盒合成(synth_music_box,原 8-bit 素材对幼儿=金属刺耳,已废弃)。
- VO 逐句归一(edge-tts 各句原声差 4dB+),高通 70Hz 去低频嗡,齿音句 treble -6dB@5k。
- 验收:整曲 loudnorm 两 pass -16 LUFS / TP ≤-1.3;STFT 扫描 3-8kHz 占比 >0.35 且 RMS >20% 峰值的窗口 = 0;全曲峰值 ≤0.65。**agy 音频评审一律不作数**(§4 已证伪: 它不读音频, 读文件系统文本编造), 音频舒适度终审 = 客观测量 + 用户亲耳。
