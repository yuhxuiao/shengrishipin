# V16 配音情感升华 · 挖土机械逻辑重构 · 彻底消除全屏晃动 (PRD)

## 1. 用户核心审查意见与病灶直击
用户指示：
> "配音的感情还是不太对 挖土的物理逻辑也不太对 为什么挖土要整个界面跟着晃动？没必要吧"

### 核心病灶解剖与解决目标：
1. **彻底消除挖土时的全屏镜头晃动 (Camera / Screen Shake)**：
   - **病灶**：在 S09 和 S23 分镜中，`shots.js` 私自配置了 `shake: { amt: 12, freq: 24 }` 与 `shake: { amt: 14, freq: 24 }`，导致相机疯狂抖动，整个天空、背景和地平线都在剧烈颠簸，产生严重的眩晕感和廉价虚假感；
   - **目标**：彻底删除所有 `cam.shake` 配置，将相机震颤幅度清零（`amt = 0`），镜头完全保持平稳推进，只保留局部机械与飞溅粒子自身的物理动态。
2. **重构挖土的真实作业物理逻辑**：
   - **病灶**：当前挖土动作把泥土卷起后，在原坑正上方直接把土倾倒回了刚挖好的深坑中（没有倾倒至侧方土堆），铲斗翻转与泥土堆叠逻辑混乱；
   - **目标**：重构真实的机械作业闭环：
     - Phase 1: 伸展入土（前探对准深坑，斗齿锐角切入）；
     - Phase 2: 深入咬土与悬挂承重微前倾；
     - Phase 3: 斗杆向内收拉、铲斗向内强力回卷（Scoop），将饱满土壤装入斗内；
     - Phase 4: 大臂抬起举斗（斗口向上防土滑落），重心后移平稳仰起；
     - Phase 5: 大臂与斗杆向侧旁旋转/倾倒至侧方土堆（Mound），铲斗外翻倾泻，泥土受重力落在土堆上，土堆实时增高；
     - Phase 6: 回程复位对准深坑，准备下一铲；
     - 做到“深坑越来越深、侧旁土堆越来越高”，绝对不往坑里倒土！
3. **配音情感与感染力全面升华**：
   - **病灶**：以往配音机械播报感重，缺乏少儿动画真挚的情感起伏与童真童趣；
   - **目标**：
     - 旁白：采用微软官方最温暖亲切的音色（如 `zh-CN-XiaoxiaoNeural`），赋予其如母亲、亲切大姐姐般的宠溺、温柔与雀跃，加入生动的语气词（“哇！”、“加油哦！”、“呼——！”、“嘻嘻！”）；
     - 挖挖：采用朝气阳光、软萌可爱的小男孩音色（`zh-CN-YunxiNeural` 或 `zh-CN-YunxiaNeural`），语调天真烂漫，在用力挖土时加入使劲呼哧声，在问候开开时带满期待与深情；
     - 混音：母带达到行业标准 **-16.0 LUFS**，时长严格维持 **228.00s（6840 帧 @ 30fps）**。
