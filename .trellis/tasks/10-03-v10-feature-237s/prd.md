## 验收标准

1. **画面三标准** (沿用 .trellis/spec/frontend/v10-animation-quality.md): 静帧美 (L4) + 动中稳 (L1 probe 侵入 0 / L2 probe_kin 硬顿挫 0 / L3 连续帧条目检) + 可复用 (renderAt 纯函数+时间轴驱动)。所有新动作/新姿态必过 L1+L2。
2. **音频** (规范 §6): 人声主导层级 / VO 增益后限幅 0.45 / SFX 峰值帽 0.30+低通 / 闪避 音乐×0.5 音效×0.6 / 双曲 crossfade / 中间文件 s16; 整曲 -16 LUFS / TP ≤-1.3 / 全曲峰值 ≤0.65 / 5k+ 刺耳窗 0。**agy 音频评审不作数, 音频终审=客观测量+用户亲耳**。
3. **新素材**: 用项目自己的生图 API, 每张过 agy 静帧评审 (仅限结构/风格) + 用户门禁; 宾果净化标准同布鲁伊 (杀米白边+低 alpha 薄雾)。
4. **物理铁律**: 真机连杆/油缸不悬空/铲斗不遮脸不穿履带/根铰隐藏脑袋后/挖土真机相位 (扎土→向车身拉刮→卷锁→拔起)/弹跳重力抛物线。
