## 2. 技术设计

### 2.1 架构复用 (样片已验证)
- `web/src/v10/feature_timeline.js` (新): 上表落为数据 — wawa 段表 [[t0,t1,action,opts]...] + bluey/bingo {enterAt,bounces} + props [气球/帽子/骨头/蛋糕 {at,popDur,锚点}] + xmark×3+金 X + dirtpile×3 + gift + cake + candles + confetti×4 + titles×2。
- `web/src/v10/feature.js` (新): 驱动, 90% 函数从 sample.js 平移 (drawBluey 泛化 drawPup(img, cfg) 供布鲁伊/宾果共用; drawGift 泛化 drawProp 供 4 种弹出道具共用)。
- `web/v10_feature.html` (新): boot 页, 复制 v10_sample.html 改引用。
- 渲染: render.mjs 已参数化, 7110 帧 ÷5 workers, 分段渲 (幕 1/2/3/4 四个 --frames 区间四个目录) 防中途返工全废。

### 2.2 新素材 (阶段 F1, 项目生图 API)
| 素材 | 规格 | 复用链路 |
|---|---|---|
| bingo.png | 宾果全身 3/4 侧面, 橙色系, 同布鲁伊画风 (平涂+描边), 净身杀白边薄雾 | drawPup 贴图 (h 480 比布鲁伊小一号) |
| cake.png | 双层生日蛋糕+数字 2 蜡烛×1 (或蜡烛×2), 布鲁伊式平涂粗描边 | drawProp 挂斗腔锚点 |
| party_hat.png | 派对尖帽, 黄蓝波点 | 挂 body 驾驶室顶 (随 bob) |
| bone.png | 卡通骨头, 米白+粗描边 | drawProp 弹出 |
- 蜡烛火光/烟雾/礼物辉光/金色 X = canvas 程序绘制, 不生图。
- 净化标准 (布鲁伊两轮经验): flood-fill 米白边 kill + erode 1px + feather + 2x upscale + alpha<48 薄雾斩杀。

### 2.3 新动作
- 无新骨骼动作 (idle/wave/dig/lift/lower/cheer/walk 全覆盖)。帽子/蛋糕/道具全走"挂 FK 矩阵"附着 (规范 §1.4: renderAt 纯函数解析重算, 禁跨帧状态)。
- 宾果"扑骨头"= 贴图平移+squash, 不走骨骼。

### 2.4 音频 (scripts/v10_feature_audio.py, 沿用 v10_audio.py v4.1 管线)
- 旁白 18 句 (N1-N18, XiaoxiaoNeural -5%, 逐句 -16 LUFS+限幅 0.45); k1 祝福句并入 N18。
- 生日歌完整版: synth_music_box 扩 4 乐句 (祝你生日快乐×2+祝开开快乐×2 变奏) ≈18s, 蜡烛段铺底, 旁白窗闪避。
- BGM Carefree 0-228s 循环 (-30 LUFS), 生日歌段 crossfade; 尾段八音盒 ring out。
- SFX 全复用 v9 库+峰值帽 0.30; 事件间隔 ≥0.35s。
- 终验: -16 LUFS / TP≤-1.3 / 峰值≤0.65 / 5k+ 刺耳窗 0。

### 2.5 审阅门禁 (规范 §2 全层)
- 新素材: 生图→净化→agy 静帧 (结构/风格)→**用户门禁**。
- 每幕渲染: L1 pose 扫描 (新姿态=托蛋糕/守礼物) + L2 (无新动作=复扫既有) + L3 连续帧条 + 用户分段门禁 → 全片合成 → 音频 → 用户终审。

## 3. 风险与对策
- **宾果定稿轮次**: 布鲁伊当年 2 轮净化; 预留 3 轮。对策: 首轮即套用布鲁伊净化参数。
- **237s 节奏拖**: L3 目检时每幕抽 3 段帧条, 用户分段门禁及时纠。
- **蛋糕托举穿帮**: 托蛋糕 pose 必过 probe L1 (规范: pose 冻结帧也扫); 蛋糕锚点用斗腔 (350,420) 已验证坐标。
- **渲染返工**: 分幕渲分目录, 改一幕只重渲一幕。
