## 8. 材质质感参数 (Three.js PBR Material Parameters)

全车采用软萌精致的“皮克斯车漆与高级搪胶玩具（Diecast & Vinyl Toy）”复合质感，严格禁止未倒角的生硬面：

```js
// 1. 车身天蓝主漆 (High-Grade Clearcoat Car Paint)
const bodyMaterial = new THREE.MeshPhysicalMaterial({
  color: 0x4A9FE2,
  metalness: 0.06,
  roughness: 0.20,
  clearcoat: 0.85,
  clearcoatRoughness: 0.08,
  reflectivity: 0.5
});

// 2. 嘴吻部与眼罩 (Soft Matte Toy Vinyl - 哑光软胶)
const muzzleMaterial = new THREE.MeshStandardMaterial({
  color: 0xF3BA54,
  metalness: 0.00,
  roughness: 0.48, // 漫反射柔和，消除刺眼杂光
  flatShading: false
});

// 3. 眼睛与鼻头 (Wet Glaze / Lacquer - 润泽瓷漆)
const wetEyeMaterial = new THREE.MeshPhysicalMaterial({
  color: 0x20232A,
  metalness: 0.00,
  roughness: 0.04,
  clearcoat: 1.0,
  clearcoatRoughness: 0.02
});

// 4. 金属铲斗与车体裙边 (Brushed Diecast Aluminum - 哑光压铸铝)
const metalPartMaterial = new THREE.MeshStandardMaterial({
  color: 0x9DA7B3,
  metalness: 0.78,
  roughness: 0.32
});

// 5. 橡胶履带 (Vulcanized Matte Rubber)
const trackMaterial = new THREE.MeshStandardMaterial({
  color: 0x2D323A,
  metalness: 0.05,
  roughness: 0.72
});
```

*   **边缘圆角率**：所有钣金转折边务必在建模时保持**倒角半径 $R \ge 0.015$**，确保高光能在边缘形成一条连续、柔韧的亮线反光带。

## 9. 光照与色彩渲染工程 (Lighting & Color Grading)

营造**温暖日光森林/金色午后庆典**的皮克斯影调，讲究冷暖对比与空间通透度：

*   **主逆光/轮廓光 (Rim Light - 金色夕阳)**:
    *   `DirectionalLight`，位置 $(3.5, 4.5, -4.0)$，照向角色。
    *   色彩：暖金橙 `#FFD39B`，强度 `3.0`。
    *   *作用*：在动臂上缘、车顶两灯和驾驶室顶部勾勒出极其通透的金黄边缘光（Rim Light），把主体从背景中剥离。
*   **主前侧光 (Key Fill Light - 柔和天光)**:
    *   `DirectionalLight` 或大型 `RectAreaLight`，位置 $(-2.5, 3.2, 3.8)$。
    *   色彩：柔和青空天蓝 `#A8D1FF`，强度 `1.4`。
    *   *作用*：照亮布鲁伊脸庞和表情，提供干净细腻的面光，与暖色轮廓光形成冷暖互补。
*   **地面弹射光 (Grass Bounce Light)**:
    *   `DirectionalLight`，位置 $(0.0, -2.0, 1.0)$，朝正上方照射。
    *   色彩：嫩草绿灰 `#C5E2A8`，强度 `0.38`。
    *   *作用*：打亮履带内部、铲斗底部暗部，彻底杜绝死黑与阴沉感。
*   **环境贴图 (Environment / IBL)**:
    *   采用晴空草地全景 HDR 经 `PMREMGenerator` 预过滤，`envMapIntensity = 0.85`。
*   **阴影质量 (Shadows)**:
    *   启用软阴影 `PCFSoftShadowMap`，Shadow Bias 设置为 `-0.0006`，底部履带接合处须带有深浓但平滑衰减的环境光遮蔽（AO 接触暗角）。
*   **后处理色调映射**:
    *   `renderer.toneMapping = THREE.ACESFilmicToneMapping;`
    *   `renderer.toneMappingExposure = 1.18;`

## 11. “呈现皮克斯质感而非廉价 CG”的 5 大关键细节

1. **绝对倒角与双层高光 (Universal Beveling & Clearcoat Highlight)**
   廉价 CG 最致命的问题是刀削般的锐利直角和塑料死光。开开全身无论是金属臂、钣金外壳还是橡胶履带，所有棱边必须具备可捕捉天光的平滑微圆角（$R \ge 0.015$）；且蓝色车身具有清漆层（Clearcoat），能同时映现环境天空柔和倒影与太阳刺点高光，产生顶级压铸玩具的触感。
2. **雕塑级五官深度与自投影 (Sculptural Facial Depth & Self-Shadowing)**
   绝不使用平面纹理贴图草率代替五官。凸出 $0.14$ 的饱满狗吻部、内嵌深邃的眼窝、独立隆起的胶囊眉毛，使角色在顺光、侧光或逆光变换时，面部能投射出富有韵律的立体自阴影（Cast Shadows），赋予面部真实的物理骨骼存在感。
3. **生动的微不对称与视线聚焦 (Micro-Asymmetry & Eye Convergence)**
   绝对的机械对称会让卡通形象沦为冷冰冰的工业构件。开开的灵魂在于生动的“单眼眨眼（Wink）”或两眼略向内倾的聚焦视线（Convergence），配合微挑的圆润眉毛与嘴角一高一低的活泼微笑弧度，瞬间消解机器感，注入淘气孩童般的生命力。
4. **冷暖交织的色彩脚本与环境泛光 (Warm-Cool Color Script & Ambient Bounce)**
   避免使用单调白光暴晒。皮克斯视效核心在于精准的冷暖互补光度学：金暖色的夕阳轮廓光（Warm Rim）切削出机械剪影，冷青色的天光柔和照亮蓝面罩，而嫩绿的草地反弹光则填补车底幽暗处，色彩层次丰满温润。
5. **童话化机械结构取舍 (Toy-like Mechanical Stylization)**
   对挖掘机繁琐冰冷的工业管线进行高阶提炼——省去杂乱的细碎线缆与锐利铰链，将关键特征（厚重液压杆、圆润履带板、大号扁平轴销、带圆角弧度的 4 齿铲斗）进行“肥化、圆化、加粗”重构，达到兼具重型机械厚重力量感与毛绒玩具般安全可爱度的完美平衡。
