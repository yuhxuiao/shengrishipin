# V9 真3D导演版 Demo(s02–s04)

## Goal

用 three.js 真 3D(本机 RTX 2060 经 WSL2 Mesa d3d12 GPU 渲染)重做剧本 s02–s04 互动段 Demo,画面质感、音画同步与幼儿友好度全面超过 v8 导演版(38s),作为全片化之前的质量标杆。

## Background

- v8 方向(AI 板件 + 代码骨骼)用户评价"大方向对,效果差强人意";Gemini 生成的部件图质感一般,用户授权"完全推翻,自己重新绘制"。
- 参考 `docs/research/repos/awesome-opus5-5-videos`(Opus 5.5 代码渲染视频提示词集)的方法论:纯函数式时间控制、代码逐帧渲染、统一设计系统、逐镜静帧审查、音效与动作帧级对齐、反复重渲。
- 用户审美基线:`output/bananan/`(Nano Banana 3D 皮克斯毛绒/搪胶玩具风、金色时刻光线、开开=布鲁伊脸挖掘机、门上"开开"字);agy 提取的角色规格书见 `output/v9/qa/charspec.md`。
- 用户要求:读图/读视频交给 agy(Gemini 3.8 Flash 多模态);自主推进到成品并验证,确认无误后通知用户。

## Requirements

1. **角色**:程序化 3D 重建开开——天蓝车身(清漆)、布鲁伊式藏青面罩、杏黄立体吻部、藏青鼻头、大眼(眼白/瞳孔/双高光)、浅蓝眉毛、微笑/张嘴(含舌头)、腮红、"开开"字标、派对帽、双履带(齿块+负重轮)、鹅颈大臂+斗杆+4 齿铲斗、液压缸随关节联动;全身倒角,无接缝/断裂。
2. **表演**:弹簧式挤压拉伸、预备与过冲、眨眼、视线、眉毛表情、开开台词口型(按音频包络)、帽子次级摆动;履带随移动转动;无瞬移。
3. **场景**:金色时刻派对草坪——草地(颜色变化+近景草簇/小花)、起伏远山与树、彩旗、气球、礼物盒、天空渐变与云;可形变土堆(挖掘留下持续凹坑)、铲斗满载土、带重力与弹跳的泥块、尘土、彩纸、闪光。
4. **光影**:暖色主光/轮廓光 + 冷色天光补光 + 草地反弹光、软阴影 + 接触暗角、IBL 反射、景深、泛光、调色/暗角/颗粒;所有镜头光向一致。
5. **镜头**:中长焦电影镜头,运镜有动机;只在短语边界切镜;节奏适合 2 岁幼儿(不晃眼、不快切)。
6. **互动 UI**:跟做提示卡、引导小手、逐句字幕、奖励徽章,统一设计语言,清晰可读且不遮挡脸部。
7. **声音**:旁白按短语重排,给每个口令留出动作时间;BGM 在人声下闪避;音效(驶入、刹车、挖土、抬斗、泥块落地、闪光、彩纸、奖励)与画面事件取自同一时间轴;响度 -16 LUFS ±1,真峰值 ≤ -1.0 dBTP。
8. **工程**:`renderAt(t)` 为 t 的纯函数(可并行、可续跑);GPU 无头渲染;子帧运动模糊 + 抖动抗锯齿;一条命令可复现出片。

## Constraints

- 不修改 v8 页面与资产(v8 可随时重渲作对比);新代码放 `web/v9.html` + `web/src/v9/`。
- 沿用现有旁白音频(`assets/audio/s02_0/s03_0/s04_0.mp3`)与 BGM(`assets/bgm/Carefree.mp3`,CC-BY)。
- 不写入 Windows C 盘;密钥不入库、不打印。
- 读图/读视频由 agy 完成,本会话负责检查与数值验证。

## Acceptance Criteria

- [ ] AC1 `output/v9/kaikai-v9-demo.mp4` 存在:1920×1080、30fps、H.264 yuv420p + AAC,时长 = 时间轴总长 ±0.05s。
- [ ] AC2 混音响度 -16 ±1 LUFS,真峰值 ≤ -1.0 dBTP(ffmpeg loudnorm/ebur128 实测)。
- [ ] AC3 帧完整:无页面报错、无缺帧、无黑帧/空白帧(程序化亮度检查)。
- [ ] AC4 同步:每句旁白都有对应字幕(±0.1s);每个互动口令结束后 0.3s 内开始对应动作;音效与对应画面事件同帧。
- [ ] AC5 agy 全片审片:无阻断级缺陷(关节断裂、穿模、闪烁、Z-fighting、字幕不可读、音画错位);美术评分 ≥ 8/10,且明确优于 v8 导演版(对比 `archive/output-tests/v8-process/contact_sheet_v8.jpg`)。
- [ ] AC6 README、plantree 交接状态更新至 V9;复现命令写明。
