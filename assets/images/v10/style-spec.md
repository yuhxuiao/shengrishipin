## 造型规则

1. **平涂 2D 矢量**: 纯色大色块, 无渐变, 无阴影贴图, 无高光质感, 无 3D 渲染感.
2. **描边**: 粗深青/深色轮廓线(近黑 navy, 非纯黑), 线条略带手绘抖动, 转角圆润.
3. **眼睛**: 超大椭圆白眼 + 小圆黑瞳(占比 ~1/5), 瞳上可点 1-2 粒白色眼神光; 上眼睑粗线.
4. **眉毛**: 粗短深蓝眉, 表情驱动主力.
5. **嘴**: 简单弧线, 开心时开口露舌(粉), 无牙或极少牙.
6. **比例**: 头身比大(头≈身), 四肢粗短, 整体圆胖软糯.
7. **背景**: 极简, 大色块分区(天/地/灌木剪影), 偶有小花/蝴蝶点缀, 无细节纹理.
8. **整体气质**: 明亮, 暖, 干净, 2 岁低幼动画; 禁止写实材质/金属反光/泥土颗粒特写.

## 视角纪律 (用户定案 09-30)

- **全片锁 3/4 主视角 + 水平镜像**, 放弃纯 90° 侧面设定 (布鲁伊/Cars 标准做法: 脸永远朝向观众, 纯侧视与"脸在车头正面"的角色设计原理性冲突, 三轮 BLOCKER 实证).
- 阶段 2 拆层只拆 `wawa_master.png` 一张; 朝右镜头用镜像.
- 生图通道: **项目 API (chatgpt2api gpt-image-2)** 为主力 (`scripts/v10_gen.py`, edit 模式锁形象); agy generate_image 车道窗口不稳定, 仅作备份. agy 聊天/评审车道直连, 用于每张资产评审.

## 脸部结构一致性 (agy 评审 BLOCKER 教训)

- 脸在**驾驶室正立面/前缘轮廓**(朝大臂方向), 侧壁只有侧窗与车门 — 严禁把五官画在侧壁上与侧窗并列.
- 布鲁伊 2.5D 侧视: 近眼+远眼**重叠双现**, 双眉齐全; 任何角度都不得画成独眼单眉.
- 吻部奶油区上有**深色横线小鼻**(双眼下方, 标志性细节), 不可丢.
- 微笑为吻部正中温和对称浅弧, 禁止歪嘴斜挑.
- 瞳孔: 独立饱满黑色长椭圆, 不贴死眼眶边缘.

## 机械一致性 (用户门禁: 2D 也要符合物理规律)

- 大臂根铰点在**车身前部中下位**(车体侧面圆形 navy 铰盖可见), 禁止从车顶/驾驶室上方长臂.
- 动臂油缸: 车身前部 → 动臂下腹; 斗杆油缸在动臂上方; 铲斗油缸在斗杆上. 油缸两端必须有铰点, 不悬空.
- 驾驶室侧窗在**前半**(司机面向大臂).
- 大臂不得跨越驾驶室车顶.
- 履带承重贴地, 上车体坐落在履带架上(有回转支承暗示).
- 阶段 2 骨骼铰点按真挖掘机连杆: 根铰(转台)→动臂→斗杆→铲斗, 各油缸随动定长.

## 挖挖(蓝色挖掘机)映射规则

- 车身/驾驶室 = 脸与身体: 主蓝 `#80C0F0` 系(可比布鲁伊略饱和一点, 仍是粉彩域).
- 前脸 = 布鲁伊式脸: 双椭圆大眼 + 深蓝眉 + 奶油色"吻部"区域(车头下沿/保险杠区).
- 深色 navy 用在: 履带, 车顶/耳状凸起(呼应布鲁伊耳尖), 描边.
- 大臂/小臂/铲斗: 同蓝色系, 关节处圆形 navy 盖片, 铲斗可用奶油黄点缀.
- 生日元素: 黄色波点派对帽(沿用历史设定).
- 禁止: 金属漆/反光/液压杆写实细节/复杂机械纹理.
